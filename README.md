# Учебный менеджер

Веб-приложение для ведения личных учебных заданий по фиксированным курсам. Проект выполняется в рамках лабораторного практикума «Практический курс веб-разработки: React, TypeScript, Node и Supabase» (ПГУ им. Т.Г. Шевченко, Физико-технический институт).

**Автор:** Мунтян Артур Олегович, группа 24ПИ1

## Тема и основной сценарий

Учебный менеджер помогает студенту вести личные задания по своим курсам. Пользователь добавляет задание с названием, описанием, курсом, дедлайном, статусом и сложностью, отмечает выполнение и находит просроченные задания.

Данные приложения: таблицы `assignments` (название, описание, курс, дедлайн, статус, сложность) и `courses` (курсы — справочник).

## Стек

- React + TypeScript
- Vite
- Node.js / npm
- Git / GitHub

Позже добавятся маршрутизация, Supabase, авторизация и Node API.

## Версия Node

`22.20.0` (записана в файле `.node-version`).

## Запуск

Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

Адрес сервера разработки выводится в терминале (обычно http://localhost:5173).

## Проверка сборки

Остановите dev через Ctrl+C. Выполните в `frontend`:

```bash
npm run build
npm run preview
```

## Что работает сейчас

- Начальный экран с названием приложения, описанием и заглушкой раздела «Мои задания».
- Проверка типов и production-сборка проходят без ошибок.

## Текущие ограничения

Данных и форм пока нет: список заданий, справочник курсов, проверка дедлайна и сложности, фильтры по курсу и статусу, Supabase, авторизация и Node API будут добавлены в следующих лабораторных работах.

ИИ использовался для создания каркаса проекта и подготовки README. Самостоятельно проверено: запуск `npm run dev` и `npm run preview`, ошибка типов при замене строки на число, успешная сборка, запуск из чистой копии репозитория.
