# Учебный менеджер

Веб-приложение для ведения личных учебных заданий по фиксированным курсам. Проект выполняется в рамках лабораторного практикума «Практический курс веб-разработки: React, TypeScript, Node и Supabase» (ПГУ им. Т.Г. Шевченко, Физико-технический институт).

**Автор:** Мунтян Артур Олегович, группа 24ПИ1

## Тема и основной сценарий

Учебный менеджер помогает студенту вести личные задания по своим курсам. Пользователь добавляет задание с названием, описанием, курсом, дедлайном, статусом и сложностью, отмечает выполнение и находит просроченные задания.

Данные приложения: таблицы `assignments` (название, описание, курс, дедлайн, статус, сложность) и `courses` (курсы — справочник).

## Маршруты и страницы приложения

В рамках ЛР 2 реализована многостраничная структура и декларативная навигация:

- `/` — автоматическое перенаправление на `/assignments` (`<Navigate to="/assignments" replace />`).
- `/assignments` — страница со списком заданий (`AssignmentsPage`): отображение карточек заданий через компонент `AssignmentCard`, обработка пустого состояния («Заданий пока нет.») и кнопка «Добавить задание».
- `/assignments/:id` — страница детальной информации о задании (`AssignmentDetailsPage`): извлечение параметра `:id` с помощью `useParams`, вывод полного описания, курса, дедлайна, статуса и сложности, ссылка возврата «К списку заданий», а также экран «Задание не найдено», если передан несуществующий идентификатор.
- `/assignments/new` — страница создания нового задания (`NewAssignmentPage`): заголовок «Создание задания», явное текстовое уведомление-заглушка о том, что интерактивная форма появится в следующей лабораторной работе (ЛР 3), и ссылка возврата «К списку заданий».
- `*` — страница 404 (`NotFoundPage`): обработка неизвестных маршрутов с заголовком «Страница не найдена» и ссылкой возврата к списку заданий.

> **Примечание о данных:** На текущем этапе все задания и курсы формируются из мок-данных (`src/data/courses.ts`, `src/data/assignments.ts`). Подключение базы данных Supabase и серверного API запланировано на последующие этапы практикума.

## Запуск проекта

Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

Адрес сервера разработки выводится в терминале (обычно http://localhost:5173).

## Проверка сборки, тестирования и линтинга

Выполните в папке `frontend`:

```bash
npm run lint
npm test
npm run build
npm run preview
```

## Что работает сейчас

- Декларативная маршрутизация на React Router v7 с общим лейаутом (`AppLayout`) и индикацией активного пункта меню.
- Страницы: список заданий (`/assignments`), просмотр деталей (`/assignments/:id`), заглушка создания (`/assignments/new`) и страница 404.
- Компонент карточки задания (`AssignmentCard`) с понятными русскоязычными метками статусов и сложности.
- Автоматическая проверка дедлайнов (подсветка просроченных заданий бейджем «Просрочено»).
- Сводка статистики по заданиям (всего, выполнено, в процессе, к выполнению, просрочено).
- Адаптивная верстка (CSS Grid, поддержка мобильных устройств до 360px, `focus-visible`, `overflow-wrap: anywhere`).
- Проверка типов TypeScript, тесты целостности данных (`npm test`) и линтер oxlint проходят без ошибок.
